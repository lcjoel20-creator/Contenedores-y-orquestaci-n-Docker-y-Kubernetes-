# Contenedores-y-orquestaci-n-Docker-y-Kubernetes-
Este repositorio contiene un material de aprendizaje sobre Contenedores y orquestación con Docker y Kubernetes, incluyendo un informe, diapositivas y un cuestionario. Su objetivo es facilitar la comprensión de cómo funcionan los contenedores, su uso en el desarrollo de software y la orquestación de aplicaciones en entornos distribuidos.
