# Docker y Kubernetes

Este repositorio contiene material de aprendizaje sobre contenedores y orquestación con Docker y Kubernetes. Incluye un informe, diapositivas y un cuestionario diseñado para reforzar los conocimientos adquiridos.

---

## Contenido del repositorio

- Informe: Explicación detallada sobre contenedores, Docker y Kubernetes.
- Diapositivas: Resumen visual de los conceptos principales.
- Cuestionario: Preguntas para evaluar el aprendizaje.

---

## Objetivo

El objetivo de este material es facilitar la comprensión de:

- Qué son los contenedores y por qué se utilizan.
- Cómo funciona Docker en el desarrollo de software.
- El uso de Kubernetes para la orquestación de contenedores.
- La importancia de los entornos distribuidos en aplicaciones modernas.

---

## Temas principales

- Introducción a los contenedores
- Arquitectura de Docker
- Imágenes y contenedores
- Redes y volúmenes en Docker
- Conceptos básicos de Kubernetes
- Pods, Deployments y Services
- Orquestación de aplicaciones

---

## Tecnologías utilizadas

- Docker
- Kubernetes
- Material de apoyo académico (PDF / PPT)

---

## Dirigido a

Este repositorio está dirigido a estudiantes y desarrolladores que desean aprender sobre:

- DevOps
- Infraestructura moderna
- Despliegue de aplicaciones
- Sistemas distribuidos

---

## Nota

Este material es educativo y sirve como apoyo para el aprendizaje de tecnologías de contenedores y orquestación.
